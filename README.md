# gulf-invest

مشروع شخصي لتعلّم الاستثمار خطوة بخطوة في **دبي (السوق الأساسي)** و**مصر (للفهم)**،
وبناء أدوات (skills + MCP) بتعتمد على مصادر رسمية ودرجة ثقة لكل معلومة.

> ⚠️ ده مشروع تعليمي شخصي، مش نصيحة مالية مرخّصة.

## المبادئ
- متوافق مع الشريعة فقط.
- نتعلم بفلوس حقيقية **صغيرة** ومخاطرة محسوبة، ونكبر تدريجياً.
- العائد دايماً يتحسب **بالدرهم**.
- كل معلومة ليها **مصدر + درجة ثقة**.
- الأداة بتنصح وتتابع بس، **مش بتنفذ** بيع أو شرا.

## هيكل الفولدر
| الفولدر | فيه إيه |
|---|---|
| `01-learn/` | اللي بنتعلمه (مفاهيم، أسواق، مصطلحات) — ملف لكل خطوة |
| `02-sources/` | المصادر ووزن كل واحد وطريقة حساب الثقة |
| `03-research/` | نتايج البحث بتاريخها ودرجة ثقتها |
| `04-decisions/` | كل قرار: أخدناه ليه (سجل قرارات) |
| `05-portfolio/` | اللي اشتريته + سجل التعلم كل أسبوعين |
| `skills/` | الـ investment-mentor skill |
| `tools/` | الأدوات (MCP) لاحقاً |

## المراحل
1. ⏳ **الفهم** — `01-learn/` (إحنا هنا)
2. ⬜ **المصادر** — قائمة موثّقة + التحقق من تراخيص التطبيقات
3. ⬜ **أول استثمار صغير** — الدرجة 1 في سلّم المخاطر
4. ⬜ **الأداة** — Gulf Markets MCP + طبقة الثقة
5. ⬜ **Agent متابعة** — ملخص دوري وتنبيهات
